# MetaHumotonic 웹 시각 체계

## 방향

검정과 어두운 중립색을 기본 표면으로, 흰색을 본문 글자로 쓴다. 시안·노랑·마젠타는 작은 면적의 강조색이다. 홈, 서비스, 연구, 학습 허브, 책, Wiki의 화면 구조는 달라도 `src/styles/tokens.css`의 같은 색 역할을 따른다. Wiki는 검정을 기본값으로 쓰되 독자가 명시적으로 고른 밝은 모드는 유지한다. 색만으로 상태·출처·권한을 전달하지 않는다.

| 토큰 | 역할 | 대표 예시 |
| --- | --- | --- |
| `--mh-bg`, `--mh-surface`, `--mh-surface-raised` | 페이지와 패널의 깊이 | 본문, 카드, 보조 패널 |
| `--mh-ink`, `--mh-muted`, `--mh-line` | 내용과 경계 | 제목, 설명, 구분선 |
| `--mh-cyan` | 기술·연결·탐색 | USL/HSWM/개발 자료, 링크, 공개 관계 |
| `--mh-yellow` | 핵심 원리·선택·초점 | 선의 공리, 현재 선택, 키보드 초점 |
| `--mh-magenta` | 사람·창작 세계·확장 | 사도, 프로그램·세계관, 창작 관계 |

강조색은 어느 한 종류의 그래프 노드나 관계를 사실로 규정하지 않는다. 각 화면의 범례와 텍스트가 해당 색의 **화면상 의미**를 설명한다. 카드를 색으로만 구별하지 않고 제목·종류·상태를 함께 표시한다.

## 표준 그래프 엔지니어링 경계

`/learn/`은 검토된 공개 카탈로그 `src/data/learning-hub.json`의 `node.kind`, `node.authority`, `edge.relation`, `edge.status`를 읽는다. 공개 화면에는 ACTIVE 관계만 표시한다. 항목의 종류·출처 권한·관계 상태를 텍스트 배지와 관계 설명 링크로 표시하며, 색은 보조 신호다. 카탈로그에서 JSON-LD와 USL 공개 입력도 생성한다. 홈의 의미 시뮬레이션은 검증된 **공개 경로의 부분 그래프**이며 전체 내부 KG의 현재 상태를 뜻하지 않는다.

서비스 목록은 별도 검토를 거친 공개 편집본이다. 프로그램 카드의 분류나 소개를 내부 플랫폼 KG의 생명주기·가동률·접근 권한으로 해석하지 않는다. 내부 MCP/서버·PostgreSQL·운영 상태와 비밀정보는 공개 UI나 공개 JSON-LD에 자동 반영하지 않는다. 공개 그래프 링크는 발견과 읽기를 위한 것이며 실행 권한이 아니다.

## 접근성과 성능

기본 글자 `#f4f7ff`와 배경 `#080a0d`의 대비는 약 18.5:1, 보조 글자 `#aeb8c5`는 약 9.9:1이다. 시안·노랑·마젠타를 `#11151a` 패널 위의 글자로 쓸 때도 각각 약 11.9:1, 14.4:1, 5.7:1이다. 작은 텍스트에 `--mh-line-strong`을 쓰지 않는다. 키보드 초점은 노란 윤곽선으로, 상호작용과 상태는 글자·경계·형태로도 드러낸다.

가벼운 정적 SVG와 요청 시 상호작용을 우선한다. 지속되는 화면 전체 캔버스 애니메이션, 큰 블러, 블렌드 효과를 기본 배경으로 쓰지 않는다. `prefers-reduced-motion`에서 불필요한 움직임을 끄고 모바일에서 그래프를 읽을 수 있는 대체 배치를 제공한다.
