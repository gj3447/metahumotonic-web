# Development: Git coordination, measurement and judgment

The frontend and metahumotonic_web_back use one canonical main writer per repo.
OMD is retired; old OMD instructions are historical, not a parallel writer grant.
Inspect status/worktree state, preserve foreign changes, stage exact owned paths,
verify before commit/push, and read back the pushed revision. Independent source
copies may test patches but never silently write the canonical checkout.

Use docs/RUNTIME.md for the pinned Node invocation. Release tests include the
shared domain projection fixture and existing wiki/ontology/consent checks.
Build measurement remains scripts/ooptdd/emit-build-trace.mjs plus the independent
Python verifier. Build success is not proof of deployment. The remote source
revision, artifact identity and live public/origin responses are separate evidence.
LakatoTree judgments require actual measurement receipts; do not invent verdicts.

The root is the Ultra Safety AI research landing; /book/ is the publication entry.
The private ontology boundary and canonical/community authority split remain intact.
The TS/Effect migration must preserve these boundaries and stateful backend contracts.
