# MetaHumotonic 회사 웹사이트

> 이 문서는 첫 로컬 개편 기록이다. 이후 사도·공리·Agent 확장과 실제 운영 반영은
> [시멘틱 회사 웹사이트](SEMANTIC_COMPANY_WEBSITE_2026-09-27.md)에 기록했다.

2026-09-27 사용자 방향: 메타휴모토닉 웹이 회사의 대표 웹사이트이고, 웹백은 그 경험을 지원한다. 회사 전체 시스템 목록은 추가 기능이다. 이 문서는 이전 작업대 중심 홈 구성과 플랫폼 중심 설명보다 최신의 웹사이트 우선순위를 기록한다.

## 방문자가 이해할 순서

1. 홈: 무엇을 연구하고 만드는 회사인지 짧게 이해한다.
2. 제품: 수풀림·버엑시·메이플리니지 소개에서 각 프로젝트로 이동한다.
3. 연구: HSWM·USL·HSPINE·LakatoTree의 질문과 연구 기록을 읽는다.
4. 회사: 자유·경제·합의의 사명과 원칙, 철학과 세계관을 만난다.
5. 자료: 읽기 지도, Wiki, Book, 실제 YouTube 게시물, GitHub 코드로 이어간다.

전체 공개 프로젝트 검색은 `/projects/`로 옮겼다. 9개 프로젝트를 분야와 키워드로 찾고 소개 페이지에서 상태와 출처를 읽는다. 기존 `/#projects` 주소는 제품 소개로 계속 이어진다. 미출시 제품을 실행할 수 있는 것처럼 꾸미지 않는다. 제품 이미지 세 개는 프로젝트 주제를 표현한 SVG 삽화이며 게임 화면이나 실제 서비스 UI가 아니다.

## 시각 방향

밝은 종이색 배경, 짙은 녹색 글자, 넉넉한 여백과 절제된 타이포그래피를 사용한다. 기존 cyan/magenta/yellow/white 2×2 고리 심볼을 헤더와 첫 화면의 브랜드 아트워크에 사용한다. 회사 소개 → 제품 세 개 → 연구 특집과 목록 → 철학 → 읽기와 영상으로 밀도를 바꾼다. 홈에서 내부 운영 그래프와 개발자용 용어가 주제보다 앞서지 않는다.

참고한 공식 회사 사이트는 [Linear](https://linear.app/), [Google DeepMind](https://deepmind.google/), [Anthropic](https://www.anthropic.com/)이다. 제품·연구·회사 소개의 분명한 위계를 참고했고, 카피와 벡터 아트워크는 이 회사의 내용으로 작성했다. 외부 폰트, 자동 재생, 영상 iframe, 추적 스크립트를 추가하지 않았다.

이번 시각 변경 범위는 홈, 프로젝트 목록과 상세, 공통 헤더·푸터, 해당 레이아웃을 사용하는 읽기 지도다. 기존 Wiki/Book/연구 원문 페이지의 별도 레이아웃은 유지한다. 전체 출판물 리디자인 완료를 의미하지 않는다.

## 구현

- Astro 정적 HTML과 CSS, 필요한 필터·메뉴·관계 탐색에만 TypeScript를 사용한다.
- 모바일 메뉴는 native details/summary이며 JavaScript 없이도 열린다. 스크립트는 Escape 닫기와 링크 선택 후 닫기를 보완한다.
- 검색에는 기존 정규화/AND 검색을 사용한다. 공개된 DOM만 읽는다.
- 기존 JSON-LD, USL, 19개 학습 노드·23개 관계와 4개 읽기 경로를 보존한다.
- 기술/기계 판독용 연결 데이터는 자료 탐색의 아래 단계에서 제공한다.
- 프로젝트 목록·메이플리니지 상세 경로를 빌드 산출물 검증과 라우트 목록에 포함한다.
